# View All → Manage 共享表面转场设计

## 目标

将 Dashboard 的 All Tools 卡片自然转换为 Manage 的 Tool Library 页面。整个过程只呈现一个连续的视觉表面；Sidebar 与 Navbar 始终固定，最终页面接管时不得出现位置、尺寸、亮度、背景或内容跳变。

## 选定方向

采用 A 方案：约 0.75 秒、克制、现代的 FLIP 共享元素转场。

不采用整张截图缩放，也不依赖浏览器 View Transition API。继续复用现有克隆层和 App Router 预加载机制，但调整其职责：克隆层负责完整的空间移动，真实 Manage 页面负责无感接管。

## 时间线

### 0–120ms：建立空间关系

- All Tools 原卡片保持内容可见，不立即清空。
- 共享表面仅产生非常轻微的抬升感，不改变内部比例。
- Dashboard 其他内容开始降低清晰度和对比度，但仍然可见。
- Sidebar 与 Navbar 不参与动画。

### 80–560ms：FLIP 移动与展开

- 共享表面从 All Tools 的真实几何位置移动到 Manage 内容区的最终几何位置。
- 使用 transform 驱动位置和整体比例；外壳尺寸与内部内容分离，避免文字和控件被横向拖拉。
- 圆角从 Dashboard 卡片状态自然收敛到 Manage 页面状态。
- 动画曲线使用强 `ease-in-out`，移动过程连续、可预测。

### 410–650ms：内容与背景交接

- 约 55% 进度后才开始背景过渡，先完成主要空间移动，再弱化港口建筑。
- Dashboard 照片逐渐过渡为同源照片的高度模糊色块状态，不出现纯色层或明显分层线。
- All Tools 内容与 Tool Library 缩略内容短暂重叠交叉淡化；二者使用相同容器坐标，不改变视觉重心。

### 560–750ms：真实页面接管

- `/manage` 在转场前已预加载。
- 真实 Manage 页面以最终位置和最终背景提前就位，不再执行 12px 下移入场。
- 克隆层与真实页面在同一几何位置交叉淡化。
- 交接完成后移除克隆层、背景 veil 和 Dashboard 周边模糊状态。
- 用户最终只感知到卡片已经成为 Manage 页面。

## 几何规则

- 目标矩形来源于 `[data-dashboard-transition-content]` 内实际 Manage 工作区的最终可用矩形。
- Dashboard 与 Manage 必须共用同一目标矩形计算函数，禁止两边分别估算 padding、top 或高度。
- 在路由接管之前缓存目标矩形；Manage 挂载后用相同矩形进行一次对齐校验。
- 响应式尺寸变化时取消当前转场并正常进入 Manage，不在错误坐标上继续播放。

## 内容比例

- 共享表面外壳负责 FLIP transform。
- 内部预览拥有固定的 Manage 设计坐标系，通过裁切窗口展示，不使用非等比 `scaleX/scaleY` 拉伸内容。
- 原 All Tools 内容延迟淡出；Tool Library 预览提前淡入，避免空白帧。

## 背景

- 转场前半段保持 Dashboard 港口背景不变。
- 后半段使用同一背景图的高模糊、低细节版本进行渐变，颜色保持 indigo、violet、深蓝主题。
- Manage 最终背景与转场 veil 使用完全相同的 CSS 变量和图像定位，避免交接分层。

## 交互与可访问性

- 转场开始后锁定重复点击，完成或取消后释放。
- `prefers-reduced-motion` 使用 160ms 透明度交接，不做位移或缩放。
- 动画期间 overlay 不接收鼠标和键盘事件。
- 路由失败或目标矩形不可用时直接进入 `/manage`，不留下 veil 或锁状态。

## 性能边界

- 主要连续动画仅使用 transform 与 opacity。
- 几何只在开始时测量一次；动画帧中不重复读取布局。
- 模糊仅作用于独立周边层，不对子树逐元素添加 filter。
- 不增加新的动画依赖。

## 验收标准

1. Sidebar 与 Navbar 从点击到 Manage 完全显示期间位置和内容不变。
2. All Tools 共享表面最终边界与真实 Tool Library 工作区逐像素对齐，交接无跳动。
3. 背景在共享表面完成主要展开后才开始变化，并与 Manage 最终背景无明显分层。
4. All Tools 内容不会立即消失，Tool Library 内容不会被非等比拉伸。
5. 正常模式约 0.75 秒完成；减少动态效果模式在 160ms 内完成淡入淡出。
6. 现有 Manage 直接点击入场、CRUD、分页、筛选、Toast 和数据库交互保持不变。

## 验证

- 为共享目标矩形、时间段、路由 handoff、取消清理和 reduced-motion 添加回归测试。
- 运行 TypeScript、定向 ESLint、相关转场测试和生产构建。
- 在桌面宽度下录制点击前、展开中段、背景交接、最终接管四个关键帧进行视觉比对。
